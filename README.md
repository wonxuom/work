# Trace

화면 위에 글라스 위젯으로 띄워 두는 local-first 업무 관리 앱입니다. ‘오늘’은 날짜별 투두, ‘태스크’는 날짜에 묶이지 않는 목표와 세부 할 일을 관리합니다. 오늘의 목록은 날짜가 바뀌면 새로 시작되고, 이전 목록은 캘린더에 그대로 남습니다.

## 실행

```bash
npm install
npm run desktop:dev
```

배포용 앱은 `npm run desktop:build`만 실행하면 빌드 후 `/Applications/Trace.app`을 자동 교체하고 다시 엽니다. 앱 데이터는 번들 밖에 저장되므로 업데이트해도 유지됩니다.

- 위젯 상단을 드래그해 원하는 위치로 옮깁니다.
- 우측 상단 확장 버튼으로 날짜별 완료 기록을 확인합니다.
- ‘태스크’ 탭 아래 입력칸에 태스크 이름을 적고 Enter로 바로 만듭니다. 태스크 옆 `+`로 할 일을 추가하고, 목표 메모는 펼친 카드에서 선택적으로 적습니다.
- 태스크 할 일의 ‘+ 오늘’을 누르면 오늘 할 일 목록에 함께 표시됩니다. 오늘 목록에서 체크하면 태스크의 할 일도 완료되고, `×`로 빼면 태스크에만 남습니다.
- 오늘 목록은 항목을 끌어 순서를 바꿀 수 있고, 순서는 날짜별로 저장됩니다. 삭제한 할 일은 5초 동안 ‘실행 취소’할 수 있습니다.
- 태스크의 할 일은 우클릭 메뉴로 오늘 할 일로 올리거나 삭제합니다. 완료된 태스크에는 할 일을 추가하지 않습니다.
- 작은 위젯에는 진행 중인 태스크만 보입니다. 태스크 완료·완료 취소는 확장 화면에서 하며, 확장 화면은 ‘진행 중’과 ‘완료’ 카드로 나뉩니다.
- `…` 화면 설정에서 ‘반투명 배경’을 켜고 끕니다. macOS 26 이상은 Liquid Glass, 이전 버전은 네이티브 반투명 소재를 쓰며, 다른 앱을 사용해도 활성 상태의 모습을 유지합니다. 입력창·탭·버튼은 흰색 기반의 불투명 UI로 분리합니다. 효과를 끄거나 지원하지 않는 환경, 시스템의 ‘투명도 줄이기’가 켜진 환경에서는 흰색 배경을 사용합니다.
- 기본 단축키는 Windows `Ctrl + ;`, macOS `Cmd + ;` 입니다.
- 데이터는 기기의 SQLite 파일에 저장됩니다.
