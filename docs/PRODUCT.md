# Trace — 데일리 위젯

## 제품 정의

Trace는 다른 앱 위에 항상 띄워 두고 사용하는 반투명 할 일 위젯이다. 사용자는 오늘 할 일을 적고 체크한다. 날짜가 바뀌면 오늘 목록은 자동으로 새로 시작하며, 과거 목록과 완료율은 확장 캘린더에서 다시 볼 수 있다.

같은 창의 ‘오늘 / 태스크’ 탭으로 날짜별 실행 목록과 장기 목표를 나눈다. 태스크는 오늘 할 일처럼 이름만 입력해 바로 만들고, 태스크마다 할 일 체크리스트와 선택 목표 메모를 둔다. 태스크는 날짜가 바뀌어도 유지되고 직접 완료·취소한다. 태스크의 할 일에 기한(오늘)을 지정하면 그날의 오늘 할 일 목록에도 표시되며, 어느 쪽에서 체크해도 같은 항목이 완료된다.

## 핵심 흐름

1. 위젯에 오늘 할 일을 바로 입력한다.
2. 완료한 항목을 체크한다.
3. 위젯을 화면의 원하는 위치로 옮긴다.
4. 확장 버튼을 눌러 날짜별 기록을 확인하거나 수정한다.
5. 태스크 탭에서 태스크를 바로 입력하고, `+`로 할 일을 추가한다. 할 일의 ‘+ 오늘’을 누르면 오늘 할 일 목록으로 올라간다.

## 제품 원칙

- 평상시에는 356×544 크기의 둥근 위젯 하나만 보인다.
- 입력, 수정, 완료 처리는 한 화면에서 끝난다.
- 날짜별 목록은 SQLite에 즉시 저장한다.
- 계정, 네트워크, 외부 상태 관리 라이브러리가 없어도 동작한다.
- 위젯 위치는 기기에 기억한다.
- 배경은 반투명 뉴트럴 톤으로 고정하고, 프라이머리 컬러는 주황색 하나만 사용한다.
- 화면 설정은 반투명 배경 켜기/끄기 하나로 단순화하고 기기에 기억한다. 별도의 흰 배경 오버레이, CSS 블러, 투명도 슬라이더는 사용하지 않는다.
- macOS 26 이상에서는 Liquid Glass(NSGlassEffectView)를 사용하고, 창이 항상 활성 상태로 보이게 해 다른 앱을 사용할 때도 글라스가 흐려지지 않게 한다(비공개 AppKit API). 그 이전 macOS에서는 NSVisualEffectView의 밝은 Popover 소재를 항상 활성 상태로 유지한다.
- Windows 10/11도 같은 기능을 지원한다. 반투명 소재 없이 흰색 배경을 쓰고 화면 설정 메뉴는 숨기며, 단축키는 `Ctrl + ;`이다. 효과를 끄거나 지원하지 않는 환경에서는 흰색 배경을 사용한다. 효과는 둥근 표면 안에만 적용하며 시스템의 투명도 줄이기 설정을 존중한다.
- 안쪽 경계는 흰색 하이라이트로 처리하고, 그림자 여백은 투명하게 유지한다.
- 입력창·탭바·상단 버튼·콘텐츠 카드는 불투명한 UI로 유지한다. 네이티브 소재는 창 배경에만 적용하며, 소재를 끄면 흰색 배경을 사용한다.
- 오늘 목록(날짜별 할 일 + 그날 기한인 태스크 할 일)은 드래그로 순서를 바꾸며, 순서는 `day_order` 테이블에 날짜별로 저장한다.
- 태스크 완료는 확장 화면에서만 처리한다. 작은 위젯은 진행 중인 태스크만 보여주고, 확장 화면은 진행 중·완료 카드로 나눈다.
- 태스크 이름·목표 메모·할 일은 입력칸을 벗어나면 즉시 저장한다. 오늘 목록에서 태스크 할 일을 빼면 기한만 지워지고 할 일은 태스크에 남는다.
- 태스크와 할 일은 기존 SQLite에 별도 테이블로 저장하고, 할 일의 기한은 `task_items.due_date`에 둔다. 캘린더 완료율은 날짜별 할 일과 그날 기한인 태스크 할 일을 합쳐 계산한다. 태스크 삭제 시 할 일도 함께 삭제한다. 데이터 내보내기에 태스크를 포함한다.

## 현재 범위

포함: 항상 위 위젯, 창 드래그, 날짜 자동 갱신, 할 일 추가·수정·완료·삭제, 캘린더 트래킹, 태스크 빠른 입력·할 일 체크리스트·오늘로 올리기·완료 관리, 글로벌 단축키, 반투명 배경 설정.

제외: 클라우드 동기화, 팀 협업, 알림, 반복 할 일. 실제 사용에서 반복 요구가 확인될 때만 추가한다.
